# Changelog

## 1.0.0

Première version complète.

### Ajouté
- Lecteur : lecture en arrière-plan, notification, écran verrouillé, file
  d'attente, shuffle, repeat, mini-player, reprise après fermeture.
- Bibliothèque : morceaux, artistes, albums, tri, recherche, pochettes.
- Identification des morceaux par métadonnées et par nom de fichier.
- Favoris, historique d'écoute, playlists et playlists automatiques.
- Analyse audio native : BPM, énergie, volume, plage dynamique, brillance.
- Classification Soft / Non-soft / À confirmer, Slow / Fast, correction manuelle.
- Écran Discover avec filtres combinables.
- Réglages : permissions, scan, reprise, analyse automatique, historique,
  nettoyage et réinitialisation des données.
- Base SQLite versionnée avec migrations (versions 1 à 3).
